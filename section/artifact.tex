\section*{Artifacts}
Two executable examples running on the Comunica~\cite{taelman_iswc_resources_comunica_2018} SPARQL federation engine accompany this paper.
The first illustrates bag-set query containment,\footnote{\url{https://github.com/constraintAutomaton/demo-semantic-query-containment-SPARQL}} and the second federated query semantics.\footnote{\url{https://github.com/constraintAutomaton/demo-federated-query-semantic}}
A detailed proof that \texttt{JOIN} cannot raise the multiplicity of a solution mapping in a \ac{CQ} is also available.\footnote{\url{https://github.com/constraintAutomaton/SPARQL-multiplicity-join}}
The implementation of \solverName{},\footnote{\url{https://github.com/SPARQL-federated-query-containment/solver}} the benchmark,\footnote{\url{https://github.com/SPARQL-federated-query-containment/benchmark}} and the analysis of the evaluation results\footnote{\url{https://github.com/SPARQL-federated-query-containment/result-analysis}} are available as well, together with the patched version of SpeCS.\footnote{\url{https://github.com/constraintAutomaton/SpeCS/tree/fix/z3-path-from-env}}

\begin{proposition}
A query $Q_2$ over a federation $F_2$ is contained into a query $Q_1$ over a federation $F_1$ given this condition is valid:
\[
Q_1 \sqsubseteq Q_2 \iff (A \land B \land C)
\]
Where subconditions $A$, $B$ and $C$ are defined as follow:
\[
A = \forall G \in \mathcal{G} \colon \eval{\mathit{QO}(Q_1)}{G} \subseteq \eval{\mathit{QO}(Q_2)}{G}
\]
where $\mathcal{G}$ is the set of every \ac{KG}.
\[
B = \forall f_1 \in F_1 \colon \exists f_2 \in F_2 \colon \eval{\mathit{QS}(Q_1, f_1)}{f_1} \subseteq \eval{\mathit{QS}(Q_2, f_2)}{f_2}
\]
Where $F_i$ is a federation associated with the query $i$ and $f_j$ is a federation member.
\[
C = \forall f \in F_1 \setminus F_2 \colon \eval{\mathit{QS}(Q_1, f)}{f} = \emptyset
\]
\end{proposition}

\begin{proof}
Query containment in the context of federated queries need to consider the provenance of the data being join.
Let's suppose a query where the federation member $f_G$ denote the local database being queried
\[
	Q = \fmj(\freq_{f_g}^{Q_1}, \freq_{f_2}^{Q_2}, \freq_{f_3}^{Q_3})
\].
Query containment of federated queries cannot use as condition, the containment of the whole query expression $Q$ with no regard to
specific federation members each sub query $Q_i$ is being issued as the computation is defined as performing an operation over a database at
a specific location, thusm it would not be the same as performing the operation at another location.
Thus the query contaiment of $Q$ as to be seen as determining the containment of $N_1$ queries from $Q_1$ with $N_2$ from $Q_2$.
There is a question remaining about which operation link the $Q_i$ in $Q$, as even if there is a $Q_i \in Q_1$ contain in a $Q_j \in Q_2$
if the $Q_{j+1}$ is join with $Q_j$ where as $Q_i$ is union with $Q_{i+1}$ the queries will not produce the result that is a subset of another query
% make it more formal
With the abscence of a query containment condition that consider the operation linking two subqueries this accentuate the relevant of the \ac{BFR} when
performing containment involving \ac{ASSF}, however, the containment algorithm need to consider bag semantic.
% what happen if the bag is the contain or the container



\end{proof}

\begin{definition}\label{def_bkg}
The \ac{BKG} of a federation $F$ is the bag union $\biguplus_{G \in \operatorname{codomain}(F)} G$ of all its members' \acp{KG}.
A triple $t$ thus has multiplicity $|\{\, G \in \operatorname{codomain}(F) : t \in G \,\}|$, i.e., the number of members whose \ac{KG} contains it.
\end{definition}

Evaluating a triple pattern $\mathit{tp}$ over the \ac{BKG} yields each solution mapping $\mu$ with the multiplicity of its matching triple $\mu(\mathit{tp})$.


\begin{proposition}\label{prop_no_overlap}
Consider a \ac{UCFQ} over a federation $F$ with union branches $U_1, \dots, U_n$, and let $F_i \subseteq F$ be the sub-federation of members appearing in $U_i$.
If, within each $F_i$, the triples matching $\mathit{tp}_i$ reside in a single member, then the \ac{UCFQ} yields the same result bag as joining each $\mathit{tp}_i$ evaluated over the \ac{BKG} of $F_i$.
\end{proposition}

\begin{proof}
Within each $F_i$, the triples matching $\mathit{tp}_i$ reside in a single member $\mathit{fm}_i$, so the branch $U_i = \fmu(\dots)$ collapses to the single request $\freq_{\mathit{fm}_i}^{\mathit{tp}_i}$ and introduces no \texttt{UNION} duplication.
The \ac{UCFQ} therefore reduces to a join of one request per branch:
\[
\fmj(\freq_{\mathit{fm}_1}^{\mathit{tp}_1}, \dots, \freq_{\mathit{fm}_n}^{\mathit{tp}_n}).
\]
Because the matching triple lies in only one member of $F_i$, it has multiplicity one in the \ac{BKG} of $F_i$, so evaluating $\mathit{tp}_i$ over that \ac{BKG} returns the same bag as the request.
Joining over all branches, the two evaluations coincide.
Since each branch is tied to its own \ac{BKG}, a triple duplicated across different sub-federations inflates no branch's multiplicity and the result bag is unaffected.
\end{proof}

We now consider the general case, where a triple matching $\mathit{tp}_i$ may reside in several members of $F_i$.

\begin{proposition}\label{prop_duplicate_fed_mem}
Consider a \ac{UCFQ} over a federation $F$ with union branches $U_1, \dots, U_n$, and let $F_i \subseteq F$ be the sub-federation of members appearing in $U_i$.
The \ac{UCFQ} yields the same result bag as joining each $\mathit{tp}_i$ evaluated over the \ac{BKG} of $F_i$.
\end{proposition}

\begin{proof}
Fix a branch $U_j = \fmu(\dots)$ and a triple $t$ matching $\mathit{tp}_j$, with $m_j$ the number of members of $F_j$ that hold $t$.
In $U_j$, the solution mapping matching $t$ is returned once by each of those $m_j$ members, so by \Cref{def_union_multiplicity} it has multiplicity $m_j$ in $U_j$.
In the \ac{BKG} of $F_j$ there is no union, but $t$ is held by those same $m_j$ members and so has multiplicity $m_j$ (\Cref{def_bkg}).
This holds for every branch and every matching triple, so each branch carries the same multiplicities under both evaluations.
By \Cref{def_join_multiplicity}, the multiplicity of a joined solution mapping is determined by the multiplicities of the input bags and by which input pairs merge to it.
Both evaluations feed the join the same per-branch multiplicities and the same solution mappings, so each joined solution mapping receives the same multiplicity in both.
The two evaluations therefore produce the same result bag.
\end{proof}

Together, \Cref{prop_no_overlap,prop_duplicate_fed_mem} establish the \ac{BFR}.
Evaluating a \ac{UCFQ} yields the same result bag, under bag semantics, as joining each branch's triple pattern $\mathit{tp}_i$ over the \ac{BKG} of its sub-federation $F_i$.
Since this rewriting targets \ac{CQ} bag containment, which has decidable fragments (\Cref{tab_decidable_containment_bag_bag_set})---in particular the projection-free case the \ac{BFR} target falls into---the \ac{BFR} resolves the undecidability issue raised by \ac{UCFQ} containment under bag-set semantics.
